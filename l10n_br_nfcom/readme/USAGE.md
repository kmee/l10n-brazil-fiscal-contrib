1. On the company, set the `OCA` electronic document processor, the digital
   certificate and the NFCom environment (electronic documents tab).
2. Create a series for document type `62` on the company.
3. On the product, enter the NFCom item classification (`cClass`, table of
   MOC item 7.8) and the unit of measure (`uMed`).
4. Create the fiscal document with type `62`, fill in the subscriber data in
   the NFCom tab and confirm: the XML is generated, signed and validated, and
   schema errors appear on the document.

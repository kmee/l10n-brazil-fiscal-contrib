1. Crie um documento fiscal com o tipo de documento 99 (DC-e) e, como
   parceiro, o destinatário dos bens.
2. Cada linha do documento é um bem declarado: descrição, NCM, quantidade e
   valor unitário.
3. Na aba DC-e, confira o tipo de emitente e, para marketplace ou
   transportadora, informe o remetente; informe a modalidade do transporte e,
   se houver, a transportadora.
4. Confirme o documento para gerar, assinar e validar o XML e envie para a
   autorização.
5. Com a DC-e autorizada, o botão "Cancel" envia o evento de cancelamento.

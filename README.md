Specific groups of Brazilian fiscal documents (NF-e, NFC-e, NFS-e, CT-e) for niche segments

Modules that fill the specific groups of the Brazilian fiscal document layouts used
by niche segments (fuel, new vehicles, weapons, pharmaceuticals, traceability,
construction works, multimodal transport and so on), on top of
[OCA/l10n-brazil](https://github.com/OCA/l10n-brazil). Groups that every company
uses belong in the core modules of OCA/l10n-brazil, not here.

This repository is an incubator: it follows the OCA addons template so that it can
be moved to the OCA organization once it holds a few tested modules.
